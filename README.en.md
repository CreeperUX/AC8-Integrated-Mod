# AC8 Integrated Mod — v2.3.15-beta.1

Optional Beta prerelease. [v2.3.6 remains the recommended stable release](https://github.com/CreeperUX/AC8-Integrated-Mod/releases/tag/v2.3.6). **Offline single-player only; do not use online or in multiplayer.**

Native UMG reticle, on-demand F1 panel and notifications, in-session sensitivity/zoom adjustments, native zoom transition handling and disable/enable tools. The latest larger ring and snapshot/layout fixes need broader in-game validation. Native rendering is not a guarantee of 120 Hz updates or zero performance impact.

[Changes, installation, limitations and rollback instructions (including English summary)](docs/RELEASE-v2.3.15-beta.1.md).

Download the complete Beta share.zip; this Beta provides the Chinese installer. Extract to a new folder outside the game, configure it, and replace the Steam launch option. For rollback, complete Beta cleanup first, install v2.3.6 separately and replace the launch option with its generated line. Do not mix payloads or used session folders.

Based on [FletcherMiya/AC8-Mouse-Aim](https://github.com/FletcherMiya/AC8-Mouse-Aim). Thanks to the original author and contributors; [licenses and credits](THIRD_PARTY_NOTICES.md) are retained.
