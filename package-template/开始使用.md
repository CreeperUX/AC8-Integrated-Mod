# AC8 鼠标飞控整合包（含头盔瞄准）

版本：2.3.6-rc.1（基于 hmd-preview.4，待实机验收）。Windows x64，Steam 游戏 Build 25201480。
**仅限离线单人，禁止用于多人游戏。** 这是分享测试版，头盔瞄准尚待完整实飞验收。

## 安装与启动

1. 正常退出游戏，等待旧版启动控制台清理完成。
2. 将本压缩包完整解压到游戏目录之外。不要直接在压缩包中运行。
3. 双击 `Start-GUI.cmd`，等待自动定位与环境检查；保留手动浏览和输入。选择范围后点击“保存设置”：
   - 飞控 + 仅比例引导（不改其他导弹性能、近炸和模型）；
   - 飞控 + 完整导弹强化；
   - 仅飞控（原版导弹）。
4. 将生成的 `Steam-Launch-Option.txt` 整行复制到 Steam → AC8 → 属性 → 通用 → 启动选项。
5. 从 Steam 或 `Start.cmd` 启动，游戏操纵类型选择 Expert／专家。也可用 `Start-GUI.cmd` 打开图形管理界面。
6. 退出游戏后，保留控制台直到归档和清理完成，再等待 Steam 云同步。

三种安装范围都包含头盔瞄准，不必安装导弹强化才能使用。后续改范围运行 `Choose-Features.cmd`；修改前先退出游戏。

## 头盔瞄准

- **F2** 开关，每次启动默认关闭。开启时圆环内出现四枚短刻度。
- 开启后仍按游戏原有的切换目标键，优先选取鼠标瞄准圈附近的有效候选。
- 这是目标选择辅助，不会绕过游戏武器的射程、锁定角或锁定时间。圆环刻度不代表完成锁定。
- 按住 C 自由观察时，选择基准仍是飞控瞄准圈，不是自由观察方向。
- 若提示 HMD UNAVAILABLE，表示功能未能启用；详见 `docs/HELMET-SELECTION.md`。

## 常用操作

| 按键 | 功能 |
|---|---|
| F3 | 原生相对机位 / 拉远机位切换，两档均保留鼠标跟随与绕飞机观察 |
| F4 | 稳健 / 积极飞控档位切换 |
| F8 | 鼠标飞控开关，不卸载导弹模块 |
| F9 | 瞄准方向回中 |
| 按住 C | 自由观察，松开后保持原飞行目标 |
| F7 | 隐藏 / 显示 Mod HUD |

## 更新与卸载

升级到新包时重新运行 Setup，替换 Steam 启动选项。不要同时运行两个整合包。
恢复原版：正常退出并等清理完成，移除本包的 Steam 启动选项。确认不再需要本包的个人备份后可删除解压目录。
异常退出后优先使用原包 `Cleanup-Offline.cmd`；历史残留处理见 `docs/CLEANUP.md`，不要直接删除来源不明的加载器。
