# 鼠标优先选目标（头盔瞄准候选）

本地版本 2.3.6-hmd-preview.4；限当前离线单人 Build 25201480。

## 操作

- **F2** 开关；每次启动默认关闭。只在游戏前台、飞行中响应不带修饰键的单次按下。
- 开启后，仍用游戏原来的切换目标键。优先选择鼠标瞄准圈附近最近的其他有效候选；如果只有当前目标，保持当前目标。
- 候选范围为以鼠标圈为中心、半径为屏幕宽度 12% 的圆。没有符合条件的目标、圈在屏幕外或数据过期时使用原生选择。
- 按住 C 时仍以飞控瞄准圈为基准，不把自由观察方向当作飞行目标。
- F2 提示使用与 F3/F4 相同的 GPU HUD：Segoe UI Medium 18、青色文字、顶部居中深色圆角底、2.5 秒显示、最后 0.4 秒淡出。显示 `F2: HMD ON`、`F2: HMD OFF` 或 `F2: HMD UNAVAILABLE`。F7 隐藏 HUD 时也隐藏此提示；旧版 GDI 回退渲染器与已有 F3/F4 一样不显示文字提示。

F3 视角、F4 飞控档位、F5 性能诊断、F6 视角诊断、F7 HUD、F8 飞控开关、F9 回中、F10 重读配置保持原有绑定。整合包没有另一个 F2 注册。自定义外部工具或以后新增 Mod 的键位需另行核对。

## 实现边界

Lua 在游戏线程中以最多 30 Hz 读取玩家组件的 `TargetCandidates`，将目标世界位置和飞控目标方向按 HUD 相同的相机基底与 500 m 瞄准球投影，比较屏幕距离。使用独立桥接读取飞控方向；现有 `frame()` 返回的是相机目标，在 C 自由观察时不等于飞控方向。

原生挂钩只接受玩家原生切换目标调用点，以 `OverrideTarget` 参数进入游戏自己的 `SelectTarget(bForcedSelect, OverrideTarget, bForceBroadcast)`。不写 `SelectedTarget`、锁定列表或导弹参数。其他调用点、脚本明确指定目标、自动切换和武器切换保持原参数。

使用前再次核对游戏线程、前台、暂停/过场状态、玩家归属、当前目标以及候选仍存在于游戏持有的数组中。样本超过 100 ms 即失效，使用后立即清空；异常时回退原生选择。函数入口和玩家调用点均检查机器码签名，发布包启动器另检查完整游戏 SHA256。反射读取失败则关闭本功能并提示不可用，不关闭飞控。

只使用游戏提供的候选集，不保证机头方向筛选之外的目标会出现。目标选择不等于导弹完成锁定；射程、锁定角和锁定时间仍由游戏判定。

## 证据与验证

在固定游戏二进制的反射描述中确认了 `bForcedSelect`、`OverrideTarget`、`bForceBroadcast` 参数；静态反汇编显示非空指定目标经过有效性检查，随后进入原生状态更新。`SelectTarget` RVA 为 `0x7296f40`，玩家调用返回点为 `0x7d630e0`。这是版本限定实现，不用于其他 Build。

新增测试覆盖鼠标离轴优先、相机偏移/滚转、屏幕外和非法目标、重复候选、采样限频、玩家归属、候选移除、当前目标变化、过期快照、暂停/关闭/脚本调用回退和参数保留。GPU 隐藏窗口测试渲染三种提示，不代表游戏内截图或实际显示帧率。

**尚未完成真实任务验收。** 验收时在两架目标分居机头与鼠标圈附近的场景按 F2，再按原切换键；查看是否选中鼠标附近目标、普通/特殊武器锁定是否正常。日志 `HMD_SELECT ... accepted=1` 仅确认原生返回目标与请求一致，不代表导弹已锁定或命中。再测试 F2 关闭、无候选、C 自由观察、F3 切换视角、检查点重生。

## preview.2 修复

首轮实飞日志确认 preview.1 的挂钩创建失败：`MH_ERROR_MEMORY_ALLOC`，因此 F2 显示不可用，尚未进入 Lua 目标读取。preview.2 在近地址分配失败时使用绝对地址跳转备用方案，完整复制经签名校验的 21 字节入口指令；新增可执行机器码往返测试覆盖跳转与回跳。目标选择逻辑、F2 和 GUI 样式保持不变。此修复仍需重启后的真实游戏日志确认。

## preview.3 准星状态

采用 A 方案：HMD 开启时，在原圆环内侧加入四枚短刻度；关闭或不可用时保留原圆环。准星形态跟随 HMD 开关持续显示，不随通知淡出。原有 F2 ON/OFF/UNAVAILABLE 通知的位置、字体、颜色和 2.5 秒显示时间不变。F3/F4 通知保持不变。旧版 GDI 回退渲染器也切换圆环刻度；不新增其原本不支持的文字通知。此形态表示模式开启，不表示武器已完成锁定。

## preview.4 生命周期修复

头盔瞄准改用当前飞机的 `TargetSelectionComponent` 属性，不再在采样周期中通过 `StaticFindObject` 查找组件类。同时修复可选导弹外观的定时对象查找，见 [生命周期修复](LIFECYCLE-FIX.md)。
