# 已知限制与验证边界

- 仅适配当前固定游戏 Build 和 UE4SS ABI。游戏更新后版本校验可能拒绝启动。
- 当前 v2.4.2 为正式版。WAR 已在多种机型上试飞，但不保证所有电脑、任务、机型或键位配置都已验收。
- 独立轴模型没有完整建模气动耦合、攻角、过载、失速和能量管理。（此条针对 PEACE；WAR 使用还原的 AC8 转动规律，但同样不改变飞机性能，失速、能量和过载仍由游戏决定。）
- 学习不保证每轴每次都成功，也不会跨游戏进程保存。不同速度区间的已验证参数覆盖不连续。
- 默认使用原生 UMG 圆环＋按需外部面板／通知，不保证120Hz显示或零性能开销。默认混合模式外部GPU不可用时不会回退到重复绘制的GDI圆环。
- 原生按键仍可能与F4/C等冲突，安装器不擅自改游戏键位。
- 导弹模块关闭时仅本项目不修改导弹；其他自行安装的 Mod 不受本项目控制。
- 近炸字段回读成功不等于所有弹种的实际触发已验证；LAAM所有机型的4发待发槽位未全面确认。
- 挂载外观的检查点修复只对符合规则的本地组件生效。启用碰撞的已发射导弹、合并在其他网格中的几何体、未知材质布局会跳过。
- 挂载维护每60个游戏线程帧最多检查16个已知缓存条目；不做全局扫描，稳定状态不写入模型。实际恢复时间随帧调度变化。
- Steam启动路径保留云同步，但不会自动解决历史云冲突。存档备份和日志含个人数据，请不要提交到仓库或随包分享。

## 测试层次

原生测试覆盖控制端点、过渡、学习参数保留、模型误差、限幅、回退和记录格式；Lua模拟测试覆盖机型规则、无效对象、检查点重置、材质回滚；安装测试覆盖导弹模块存在/缺席、加载列表和就绪条件。

这些检查与真实游戏启动、第三人称外观、命中行为和飞行手感是不同层次。特别是模拟中的响应时间变化不应作为游戏性能提升百分比宣传。
