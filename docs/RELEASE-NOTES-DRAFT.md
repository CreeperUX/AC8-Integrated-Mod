# AC8 Integrated 2.3.6-rc.1

完整发布候选包，整合最新头盔瞄准、相机和生命周期修复，以及 CreeperUX 图形安装器。当前尚未批准公开发布。

- 三种安装范围：飞控＋仅比例引导、飞控＋完整导弹强化、仅飞控。
- F2 头盔瞄准默认关闭；开启后四向刻度与原有通知共同显示状态。三种范围均包含此功能。
- F3 两种视角及 C 自由观察；保留剧情结束后的自动回中。
- 修复任务退出期间的若干重复全局对象查找，保留检查点外观恢复。
- 自动定位 Steam 和游戏，同时允许手动选择；集成备份清理、诊断及宿主兼容修复。

完整解压到游戏目录之外，双击 **Start-GUI.cmd**。核对自动定位结果，选择范围并保存；将启动选项复制到 Steam 后启动。正常退出后等待清理。仅适配 Windows x64、Steam Build 25201480 和离线单人任务。

升级时使用新解压目录，并更新 Steam 启动选项。请分享原始 ZIP，不要转发游玩后的 sessions 或备份目录。

自动化和打包检查已执行；任务退出、回机库、检查点重生及不同设备的实际体验仍待验收。最终发布说明应在用户确认实机结果后更新。
