# 2.3.6-rc.1 发布准备报告

日期：2026-10-05。状态：发布候选，未公开 Release，实机验收与发布批准待完成。

## 本次基线

来自开发主线 `feature/camera-context` 的 `e7d19d4` 及当时尚未提交的 hmd-preview.4 改动。冻结文件及其哈希记录在 [SOURCE-SNAPSHOT.json](SOURCE-SNAPSHOT.json)。在独立候选工作树构建，未改写开发目录、游戏目录或已激活的本机版本。

本次重新编译当前原生源码。原生版本标识为 2.2.2，整合包版本为 2.3.6-rc.1，两者含义不同；不再使用 GUI-Test2 的旧原生 DLL。

## 功能与安装器适配

| 项目 | 候选包情况 |
|---|---|
| 三种安装范围 | guidance / full / none，保留旧配置迁移与未保存状态检查 |
| 头盔瞄准 | 三种范围均包含；F2 游戏内开关，每次启动关闭；开启后四向刻度，原通知保留 |
| 视角与观察 | F3 切换两种机位；C 绕飞机观察；保留任务/剧情后的回中机制 |
| 生命周期修复 | 包含 preview.4，减少场景退出后的旧对象查找，保留检查点外观恢复 |
| 环境与路径 | 自动定位 Steam/游戏、多库候选、手动选择、只读检查 |
| 安装器加固 | 包含主线 86f6990 的宿主隔离、哈希兼容、Steam 配置检查和清理保护 |
| GUI 信息 | 显示实际 package-info 版本，新增 F2/F3 操作说明；没有将运行时开关伪装为安装范围 |
| 完整性 | 强制包含 helmet、view_context、camera-settings、selected_spec 和 installation_mode；清单被重建也不能绕过缺文件检查 |

相机初始机位及距离、高度已有 INI 配置链路；GUI 本次不增加未经主线确认的 HMD 默认开启或持久化选项。

## 已执行验证

- 原生重新构建及模式、全模型、机动策略、记录器、观察入口、相机上下文、头盔选择测试通过。
- GPU 隐藏窗口渲染、透明像素、尺寸切换及资源释放测试通过；提交次数不代表实际显示帧率。
- 六组 Lua 回归通过：外观/生命周期、模块集成、三模式隔离、观察入口、相机上下文和头盔选择。
- 十一组 PowerShell 验证通过：功能部署、Setup、包完整性、清理、安装体验、GUI、主题、定位、宿主隔离、Steam 桥接与无滚动条布局。
- 三种范围均实际复制 HMD/相机脚本；缺少 helmet.lua 即使清单同步删除也会拒绝安装。

主界面已移除滚动容器；16种布局覆盖深浅主题、窗口尺寸、多候选和长状态文字，关键按钮与提示均未裁切。

完整包以同一构建的 FILES.sha256、ZIP 校验及最终解压结果为准。原始测试输出保存在本地隔离测试目录，不随包公开。
