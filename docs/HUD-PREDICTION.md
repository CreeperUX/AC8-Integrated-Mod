# HUD 显示相机预测实验

版本：2.3.11-prediction-preview.1。控制基线：2.3.9-independent-preview.2。该包从基线随包源码独立构建，未引入已撤回的屏幕偏置持续转向方案，也没有新的输入采集进程。

## 操作

- 使用原 Steam 启动方式。候选默认请求显示预测，条件不足时自动使用真实快照。
- **Ctrl+End** 切换原始/显示预测；**F1** 显示 ACTIVE、WAITING 或 RAW、当前预测毫秒数、相对原始投影的像素偏移和10秒窗口回退帧数。
- 世界方向目标、鼠标灵敏度、飞控档位、C自由观察、原生目标注视与缩放规则沿用2.3.9。

## 实现

为姿态桥接收到时刻和最终相机采样时刻分别记录QPC，不再用姿态旧时间戳计算相机预测时长。显示线程独立维护历史和四元数角速度，连续8个有效样本后，最多向前补足当前时刻的8ms、且不超过半个源帧间隔。只预测朝向，不预测FOV或机位，不生成新的控制目标。

显示投影相对原始投影的偏差限制为画面高度0.35%（1080p约3.78px）；同时约束圆环和可见机头连接端。异常/变速反向/源间隔超限/时间倒退/窗口与场景变更/临近屏幕边缘/FOV明显变化时回退并重新准备。C观察、暂停、失焦、原生注视、回中与相机切换期间不用预测。

这是真实世界目标的显示投影实验，不是游戏画面插帧，不能保证与每一帧背景完全吻合。原始模式即时显示最新真实目标，不加入原先延迟一帧的二维圆环插值。

## 记录

自动记录 HUD_PIPELINE、HUD_INPUT、HUD_PREDICTION 和 HUD_TIMING。后者分别记录原始输入到达、目标更新、姿态收到、最终相机和提交间隔，以及姿态/相机年龄的p50/p95/p99。统计使用0.25ms分桶，32代表32ms及以上；事件间隔大于等于250ms视为闲置间隔，不纳入间隔分布。统计不等同显示器实际FPS。

## 验证范围

通过控制代码与基线的逐函数核对（仅剔除新增诊断语句）、所有Lua及模型头文件字节一致检查，以及预测开/关不写真实指令、目标、相机命令和飞控策略的运行时测试。

数学测试覆盖四元数换算、±180度、大滚转、过去数据预测、暖机、快速反向、FOV/epoch变化、过期/屏幕外及像素限制；用合成高频匀速轨迹隐藏中间采样进行误差对照。匀速轨迹结果不代表真实飞行所有场景。

建议同一机型、场景、相机档位和灵敏度，交替使用 Ctrl+End 比较缓慢移动、快速反向、鼠标静止时转弯与缩放。重点反馈圆环是否顺滑、是否相对背景漂移或出现跳动，以及控制手感是否相同。正常退出并保留控制台至归档完成即可。

当前是测试版；真实显示收益与背景对齐仍待实飞。旧版本保留用于回退。
