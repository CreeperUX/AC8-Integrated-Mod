# 玩家图形界面 · 本地预览

此界面尚未发布。完整解压预览包到游戏目录之外，双击 **Start-GUI.cmd**。

Windows 自带的 Windows PowerShell 5.1 与 WPF 即可运行界面；普通使用不需要 Python、NumPy 或另装 Web 服务。

## 使用方式

1. 点击“选择文件夹”，选择游戏根目录或 Win64，也可以直接粘贴 AceCombat8.exe 路径。
2. 核对 Steam 程序位置。通常会自动找到，也可以手动选择 steam.exe。
3. 选择“仅鼠标飞控”或“鼠标飞控 + 导弹强化”。
4. 点击“检查环境”，查看结果。检查在后台执行，不写入游戏文件。
5. 点击“保存设置”。会进行临时文件写入检查，再保存本包配置；保存失败时尝试恢复原配置。
6. 点击“复制启动选项”，粘贴到 Steam → 游戏属性 → 通用 → 启动选项。仍由玩家完成这一步。
7. 点击“从 Steam 启动”，或在 Steam 点击开始游戏。游戏运行期间保留原启动控制台，退出后由原流程清理。

“备份并清理”使用现有清理核心：先确认残留属于本整合包，再备份并校验。未知加载器、其他 Mod、运行中的游戏或无法确认归属的目录会停止处理。清理不清除 Steam 启动选项；需要停用 Mod 时请同时移除该选项。

状态提示始终显示在窗口下方。后台操作期间按钮暂时禁用，完成后恢复；当前操作完成前不能关闭窗口。错误细节写入 diagnostics，可用“打开诊断文件夹”查看。
