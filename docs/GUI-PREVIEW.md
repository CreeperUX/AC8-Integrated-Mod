# 玩家图形界面 · 本地预览

此界面尚未发布。完整解压预览包到游戏目录之外，双击 **Start-GUI.cmd**。

Windows 自带的 Windows PowerShell 5.1 与 WPF 即可运行界面；普通使用不需要 Python、NumPy 或另装 Web 服务。

## 使用方式

1. 点击“选择文件夹”，选择游戏根目录或 Win64，也可以直接粘贴 AceCombat8.exe 路径。
2. 核对 Steam 程序位置。通常会自动找到，也可以手动选择 steam.exe。
3. 从三种安装范围中选择一项（均含鼠标飞控）：
   - **仅比例引导**：只调整玩家导弹的比例引导，保留原版性能、锁定、伤害、装填、近炸设置和外观。
   - **完整导弹强化**：启用现有比例引导、性能强化、近炸参数和外观替换。
   - **仅鼠标飞控**：不安装导弹模块，导弹保持原版。
4. 点击“检查环境”，查看结果。检查在后台执行，不写入游戏文件。
5. 点击“保存设置”。会进行临时文件写入检查，再保存本包配置；保存失败时尝试恢复原配置。
6. 点击“复制启动选项”，粘贴到 Steam → 游戏属性 → 通用 → 启动选项。仍由玩家完成这一步。
7. 点击“从 Steam 启动”，或在 Steam 点击开始游戏。游戏运行期间保留原启动控制台，退出后由原流程清理。

“备份并清理”使用现有清理核心：先确认残留属于本整合包，再备份并校验。未知加载器、其他 Mod、运行中的游戏或无法确认归属的目录会停止处理。清理不清除 Steam 启动选项；需要停用 Mod 时请同时移除该选项。

状态提示始终显示在窗口下方。后台操作期间按钮暂时禁用，完成后恢复；当前操作完成前不能关闭窗口。错误细节写入 diagnostics，可用“打开诊断文件夹”查看。

## CreeperUX UI Kit 设计来源

本地预览 2 使用 GitHub 仓库 `CreeperUX/CreeperUX-UI-Kit` 的 **2.4.0**，固定提交 `586e23784d8f51cbe8713e583bcf0d92c473f2d0`（已核对远端 main）。适配来源为 `tokens/tokens.json` 与 `kit/ui/ui.css`。

这是 WPF 原生控件适配：配色、表面层级、5/6px 控件与面板圆角、字号、控件边界、选中与键盘焦点状态来自 Kit；操作逻辑仍使用本项目的安装、启动与清理核心。默认深色，可点击右上角切换浅色。清理确认框也使用同一主题；文件选择器与系统窗口边框遵循 Windows。

`ui/creeperux/SOURCE.json` 记录来源及令牌哈希；令牌快照随包保存。Chakra Petch SemiBold 和 Share Tech Mono 从 Kit 的 WOFF2 无损解码为 WPF 可加载的 TTF，保留字体名称、字形及 SIL OFL 许可；中文使用系统字体回退。包内不需要安装字体。

高对比度模式使用 Windows 系统颜色；减少动画时不使用不确定进度动画。真实游戏运行与多显示器 DPI 体验仍待玩家验收。此版本仅为本地预览，未推送或发布到 GitHub。

## 三模式适配

`2.3.4-gui-preview.1` 接入另一分支已实现的三种安装范围（提交 `94e9ec118125803d2b22b5f57f6784bfb8c4ea06`）。GUI、后台任务与启动检查使用 `missile_mode=guidance/full/none`，不会把“仅比例引导”合并成“完整强化”。界面重开时恢复已保存模式；修改后需保存，下次启动生效。

旧 `missile_enhancement=1/0` 分别读取为 `full/none`，保存后迁移成新格式。新包默认完整强化，与三模式命令行安装器一致。原配置在其他包目录时，不会自动跨包导入，应按原选择重新设置。

飞控继续使用 v2.3.2 基线原生 DLL；底层比例引导的范围由三模式实现控制。隔离测试验证 GUI 保存、配置回读、实际模块部署和 Lua 安装模式的对应关系，并运行三模式 Lua 回归。真实游戏内导弹行为仍待验收。本地预览未发布。

## 自动定位与环境检查（GUI-Test2）

打开界面后会在后台自动查找 Steam 和 AC8，并在路径确定后执行已有的安装包、游戏版本、运行状态与残留检查。来源包括 Steam 注册信息、运行中的 Steam 程序位置、默认安装目录、libraryfolders.vdf 和 AC8 安装清单；支持多盘符游戏库、自定义安装文件夹，以及新旧库清单格式。

只在输入框为空且候选唯一时自动填入。已保存或手动填写的路径始终保留，即便路径已经失效也会提示检查，而不擅自替换。多个候选会显示下拉列表，选择后自动检查；找不到时仍可使用“浏览…”或直接输入路径。需要重新扫描时点击“自动定位”。

自动阶段只读取注册信息、库清单与必要文件，不修改 Steam 配置，不清理残留，也不保存安装设置。写入权限探测仍在点击“保存设置”时执行；确认路径和安装范围后再保存即可。失效或损坏的库清单会给出提示，仍允许手动指定位置。
