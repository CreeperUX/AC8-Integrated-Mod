# 游戏内诊断与灵敏度调整

版本 2.3.15-beta.1。没有加入自校准或后台自动调节。

在任务飞行中按 **F1** 打开/关闭键盘操作面板，显示当前灵敏度、启动值、飞控档位、相机档位、HMD 状态、相机 FOV 和姿态数据年龄。不是可点击菜单，游戏不会暂停。

- **Ctrl + Page Up**：灵敏度乘 1.1。
- **Ctrl + Page Down**：灵敏度除 1.1（与增加操作互逆，约减 9.1%）。
- **Ctrl + Home**：恢复本次配置加载的启动值。
- 每次独立按下调整一次，持续按住不连发。范围 0.01–1.00。
- 两个调整键同时按下不更改；暂停、失焦、过场/目标注视、飞控关闭时不调整。
- 更改只作用于本次运行，不写回根目录 INI。F10 重读配置会恢复配置值并按原行为回中。
- 要永久保存，将面板中的数值写入根目录 MouseAim-Settings.ini 的 sensitivity；关闭游戏后编辑，下次启动应用。

面板列出 F2 头盔、F3 相机、F4 飞控、F5 性能日志、F6 镜头日志、F7 HUD、F8 飞控、F9 回中、C 自由观察、Alt+F7 参考准星及原生长按目标键。F1 打开时会显示 HUD。F7 隐藏 HUD、F8 关闭辅助或游戏接管相机时面板也隐藏，恢复后继续显示。

面板和数值提示使用按需外部 GPU HUD；默认混合模式发生外部绘制故障时不自动回退到外部圆环，快捷键仍调整并记录日志。姿态数据年龄只反映最近数据的新鲜程度，不代表测量到的屏幕延迟或 FPS。

不抢占游戏输入；如果自定义游戏/外部工具也绑定了 F1 或 Ctrl+PageUp/PageDown/Home，请解除冲突。此次未修改控制律、导弹配置、相机接管或崩溃修复逻辑。硬件渲染测试与逻辑测试不等同于真实游戏验收。

## 参考准星开关（2.4.1）

按 **Alt+F7** 显示／隐藏机头参考准星（十字），弹出提示，F1 面板中“Gun cross”一行显示当前状态。只作用于本次运行，F10 重读配置会恢复配置值。启动时的状态由根目录 MouseAim-Settings.ini 的 `hud_boresight` 决定（1 显示，默认；0 隐藏），关闭游戏后修改，下次启动应用。同时按住 Ctrl 或 Shift 时不切换；单按 F7 仍是显示／隐藏整个 Mod HUD。

## 自由观察右键放大

按住 C 自由观察时再按住右键，将游戏原生放大变化增强 1.75 倍，进入和退出沿用原生 FOV 过渡。只缩小视场，不改变绕机中心或机位距离。最低 FOV 15 度，游戏自身更窄时保持其原值；因此达到下限后不会继续增加。原生长按目标注视仍由游戏处理。

关闭游戏后可以在 MouseAim-Settings.ini 调整 `free_look_zoom=1.75`，范围 1–3，1 表示不加额外倍率。HUD、鼠标投影与头盔目标选择使用有效视场角。

## 放大快捷键与刷新节奏

Alt+PageUp/PageDown 每次增减放大增强系数 0.25，范围 1–3；Alt+Home 恢复启动值，仅本次运行有效。C+右键沿用原生长按门槛和缩放过渡，1.75 是对原生放大变化的增强系数，不是始终叠乘1.75。

默认 hud_renderer=3：圆环由游戏 UMG 绘制，F1 面板目标20Hz，通知期间目标60Hz；面板关闭且无通知时不提交外部帧。两者共享硬件和部分状态，不保证无性能影响。hud_fps=120 不把原生圆环变成120Hz；Ctrl+End 不为原生圆环开启插值或预测。诊断中的更新／提交频率不等于实际显示FPS。
