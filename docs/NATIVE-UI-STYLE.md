# 原生准星＋按需面板

2.3.15-beta.1 默认 hud_renderer=3。

- 原生UMG：完整青色圆环、深色描边、HMD四角括号（2.4.0 起，原为四枚内刻度）与朝向机头的三枚短刻度。圆环控件为120设计单位，比上一版增大50%。2.4.0 起另有机头参考准星，见下文。
- 移除两秒固定验证标记。普通目标跟随使用归一化锚点，不再因为GetCachedGeometry为0而一直停在中心。优先读取GetPaintSpaceGeometry；游戏离屏4K HUD不提供尺寸时，尺寸沿用其2160高的设计参考，位置不依赖该参考。
- F1面板和F2/F3/F4/灵敏度/倍率通知继续使用既有CreeperUX GPU界面，只显示文字与面板，不重复绘制圆环。关闭面板且没有通知时隐藏外部窗口、不绘制或提交。面板刷新目标20Hz，通知期间60Hz。
- 原生纹理由包内自有PNG导入并由GameInstance持有，避免重复导入和跨关丢失。导入失败时圆环回退游戏自带贴图，连接刻度可暂不可用，日志记录STYLE_FALLBACK。

## 2.4.0：参考准星与头瞄圆环

- **参考准星**：机头（机炮）方向 500 m 处画一个中心留空的十字（`ui-native/boresight.png`），与圆环同色、同线宽、同一套投影。飞控到位时十字落在圆环中心。
- **为什么需要**：游戏原生准星会下沉，与机炮实际弹道对不上。AC8 没有气动迎角，平飞时速度方向与机头重合，机炮弹道在 500 m 内的下坠小于 0.1°，所以这个十字可以代表机炮指向。
- **独立绘制**：十字不依附圆环，圆环在屏幕外或相机背后时（例如按住 C 自由观察）也显示，只要机头在画面内。
- **头瞄圆环**：F2 开启时圆环外加四角括号，替换原来的四枚内刻度，避免与十字混淆。按住 C 时，括号圆环画在视线方向，鼠标圆环恢复普通样式，见 [头盔瞄准](HELMET-SELECTION.md)。
- **开关（2.4.1）**：`MouseAim-Settings.ini` 的 `hud_boresight` 决定启动时是否显示十字（1 显示，默认；0 隐藏）。飞行中按 Alt+F7 临时切换，弹出提示，F1 面板显示当前状态。隐藏十字不影响鼠标圆环、方向刻度和头瞄圆环。

快捷键：F1面板，F2头盔，F3机位，F4飞控档位，F7显示开关，Alt+F7参考准星，F8飞控开关，F9回中；Ctrl+PageUp/PageDown/Home调灵敏度，Alt+PageUp/PageDown/Home调放大。仅本次运行的调节规则沿用原版。

本地验证：零缓存尺寸仍可目标跟随、纹理复用/持有、HMD变化、刻度、隐藏与出屏保护；GPU混合模式不绘制第二枚圆环，静默时不提交。实际游戏纹理导入、最终显示大小和性能待实飞。仅限离线单人。

本次修正：圆环目标与相机取自同一份已发布快照，方向刻度复用同一帧；保持同一所属画布，临时缺失尺寸时保留上次有效尺寸，减少布局跳变。未增加低通平滑或预测，飞控算法不变。此修正针对代码中可确认的时序不一致，不能替代实机抖动验证。
