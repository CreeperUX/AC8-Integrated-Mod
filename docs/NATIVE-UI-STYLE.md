# 原生准星＋按需面板

2.3.15-beta.1 默认 hud_renderer=3。

- 原生UMG：完整青色圆环、深色描边、HMD四枚内刻度与朝向机头的三枚短刻度。圆环控件为120设计单位，比上一版增大50%；不添加第二个机头十字。
- 移除两秒固定验证标记。普通目标跟随使用归一化锚点，不再因为GetCachedGeometry为0而一直停在中心。优先读取GetPaintSpaceGeometry；游戏离屏4K HUD不提供尺寸时，尺寸沿用其2160高的设计参考，位置不依赖该参考。
- F1面板和F2/F3/F4/灵敏度/倍率通知继续使用既有CreeperUX GPU界面，只显示文字与面板，不重复绘制圆环。关闭面板且没有通知时隐藏外部窗口、不绘制或提交。面板刷新目标20Hz，通知期间60Hz。
- 原生纹理由包内自有PNG导入并由GameInstance持有，避免重复导入和跨关丢失。导入失败时圆环回退游戏自带贴图，连接刻度可暂不可用，日志记录STYLE_FALLBACK。

快捷键：F1面板，F2头盔，F3机位，F4飞控档位，F7显示开关，F8飞控开关，F9回中；Ctrl+PageUp/PageDown/Home调灵敏度，Alt+PageUp/PageDown/Home调放大。仅本次运行的调节规则沿用原版。

本地验证：零缓存尺寸仍可目标跟随、纹理复用/持有、HMD变化、刻度、隐藏与出屏保护；GPU混合模式不绘制第二枚圆环，静默时不提交。实际游戏纹理导入、最终显示大小和性能待实飞。仅限离线单人。

本次修正：圆环目标与相机取自同一份已发布快照，方向刻度复用同一帧；保持同一所属画布，临时缺失尺寸时保留上次有效尺寸，减少布局跳变。未增加低通平滑或预测，飞控算法不变。此修正针对代码中可确认的时序不一致，不能替代实机抖动验证。
