# v2.5.3 — 适配 11 月游戏更新

**正式版。仅限离线单人，禁止带 Mod 进入线上或多人模式。** 飞控与 v2.5.2 相同（WAR v13.8 / PEACE）。

## 更新内容

- **适配 2026-11-02 游戏更新（Steam Build 26002268）**：启动器接受新版游戏，不再提示“游戏版本与本包适配版本不一致”。原生相机（F3）和头瞄选目标（F2）按游戏版本使用各自的地址，在新版中照常可用。
- 旧版 Build 25201480 继续支持；其他版本的游戏仍会拒绝启动，不会绕过任何校验。
- 感谢 bakasayaka 完成这次适配（#11），以及 kirisame000 在 #9 中提供的定位结果。

## 安装与升级

- **安装版**：在启动器右上角点击“检查更新”。
- **新安装**：下载 **AC8-Integrated-Setup-v2.5.3.exe** 运行；便携版下载 **AC8-Integrated-v2.5.3-share.zip**。
