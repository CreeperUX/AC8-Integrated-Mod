## Mod 固定快捷键

| 按键 | 功能与条件 |
|---|---|
| 鼠标移动 | 指定飞行目标方向，由 Mod 协调飞机姿态 |
| 按住 C + 移动鼠标 | Mod 自由观察；松开后保留原飞行目标。机头参考准星照常显示 |
| F2 | 开关 HMD；每次启动默认关闭。开启后鼠标圆环外加四角括号；按住 C 时括号圆环移到视线方向，切换目标按视线方向选 |
| F3 | 原生相对机位／拉远跟随机位切换；与游戏的 V 视角切换不同 |
| F4 | PEACE／WAR 飞控切换 |
| F5 | 性能诊断，供排错使用 |
| F6 | 视角诊断，供排错使用 |
| F7 | 显示／隐藏 Mod HUD 与提示 |
| F8 | 鼠标飞控开关，不代表卸载导弹模块 |
| F9 | 瞄准方向回中 |
| F10 | 重读本次运行副本的配置并回中；包根设置通常在下次启动应用 |

## 使用时注意区分

- **C 与左 Alt**：二者都是当前游戏保存的视角控制绑定，但 Mod 的自由观察路径直接检测 C。左 Alt 不是 Mod 的等价备用键；使用 Mod 绕机观察请按住 C。
- **V 与 F3**：V 是游戏原生视角切换；F3 改变 Mod 的机位方案。使用 Mod 时按安装说明选择游戏第三人称视角。
- **F2／F3／F4**：必须松开 Shift、Ctrl、Alt 后单按。当前油门键正是左 Shift／左 Ctrl，因此持续加减速时按这些功能键可能不会切换。
- **W/S、A/D、Q/E**：Mod 默认以这些键识别手动接管。WAR 中按住俯仰／偏航键接管三轴、只按滚转键只接管滚转；PEACE 中 W/S 还会让出自动滚转。若在游戏设置中改绑，请在启动器“键位设置”中同步修改，见 [自定义键位](CUSTOM-KEYBINDINGS.md)。
- **F 或鼠标右键**：F2 开启后仍使用游戏原目标切换键。HMD 改变候选优先级，不绕过武器射程、锁定角或锁定时间。
- 数字 7/8/9/0 与 F7/F8/F9 等功能键不是同一组键。原生 Z、G、方向观察键按游戏当前上下文生效；此页记录绑定，不代表所有组合已逐项完成实机验收。
