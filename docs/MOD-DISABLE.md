# 快捷停用与原版启动

本 Mod 仅限离线单人，禁止带 Mod 进入多人游戏。F8 只关闭飞控，不会卸载 UE4SS。

## 停用

1. 正常退出游戏，保留启动控制台等待清理结束。
2. 双击 **Disable-Mod.cmd**，或在 Start-GUI.cmd 界面选择“停用 Mod／恢复原版启动”。
3. 工具检查游戏/辅助进程是否已退出，必要时只清理能确认归属的旧会话，然后核验本项目的 dwmapi.dll、ue4ss、steam_appid.txt 残留。
4. 成功后继续从 Steam 启动。桥接脚本会再次检查，并原样执行 Steam 提供的默认命令；不会再部署本 Mod，也不会直接跳过官方启动流程。

发现未知加载器、清理错误或运行中的游戏会拒绝切换/原版启动，不会为了通过检查删除未知文件。关闭控制台不是卸载。

## 恢复 Mod

先退出游戏，再运行 **Enable-Mod.cmd** 或图形界面的“恢复离线 Mod”。下次 Steam 启动重新进入 Mod 单人模式。

移动安装包或使用另一个安装目录后，请重新 Setup 并核对 Steam 启动选项。旧版本桥接脚本不自动获得此功能；使用当前包或本机已更新的统一入口。

## 检查边界

工具不修改反作弊程序、服务或检测结果。原版路径清除本项目离线子进程使用的 EOS_USE_ANTICHEATCLIENTNULL 环境覆盖，再执行 Steam 原始命令。本检查只覆盖本项目已知临时文件及会话，不保证其他 Mod、游戏文件改动或反作弊状态符合线上要求；需要时通过 Steam 校验游戏文件。不会自动进入线上对局。
