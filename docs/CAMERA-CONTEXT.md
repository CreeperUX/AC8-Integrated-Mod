# 视角选择与任务回中候选版

本版延续2.3.2飞控算法，提供两种镜头和任务/过场后的自动回中。尚待真实任务验收。

## 两种视角

- **游戏原生视角**：保留游戏计算的摄像机位置，方向继续使用与拉远档相同的鼠标跟随。游戏内选择第三人称；F3仅切换机位，不重置方向平滑。Mod仍提供鼠标飞控与圆环，按实际最终镜头位置/旋转投影。
- **拉远跟随视角**：默认机后36米、上方6米（此前为30米/6米）。改变机位，不改变游戏FOV与后处理。

**切换直接在游戏内完成，不是安装选项。按F3**在飞行中临时切换两档，不重置飞行目标；下次启动读取保存设置。F3仅在游戏前台、飞控活动且非暂停/剧情接管时响应。F4仍为飞控档位，F8仍为飞控开关，C仍为自由观察。

也可关闭游戏后编辑MouseAim-Settings.ini：

```ini
camera_mode=1
camera_distance_m=36
camera_height_m=6
```

camera_mode=0为游戏原生，1为拉远；拉远距离可在10–100米内设置，高度0–20米。距离/高度只影响拉远档。更改配置下次启动生效；F10读取本次运行副本。

## 自动回中

任务初始化、新玩家飞机、剧情相机归还控制或暂停返回时，等待控制状态连续稳定约0.2秒，然后仅回中一次。清空过场累积的鼠标输入，目标重新对齐机头方向。初始出生仍保留原有0.5秒变换稳定等待。

检测同时使用本地ViewTarget归属、已核对的玩家输入许可字段、可用的控制器剧情/忽略输入状态，以及既有事件/ImpactCamera检测。缺失的可选字段只探测一次，不反复报错或凭缺失值禁用飞控。

松开C不触发剧情回中；直接读取本项目C键状态作为分类补充，即使焦点元数据不可用也保留自由观察语义。F8重新启用飞控会回中。过场/暂停期间暂停控制与相机覆盖。

## 技术边界与验证

AC7现有实现也是固定机位，采用其游戏单位下的300/60偏移，即30米/6米；AC8原有3000/600偏移已是相同物理距离。本次开放配置并将拉远默认值设为36米，没有移植AC7的地址、内存布局或飞行动力学参数。

AC8仍使用独立核对的相机缓存与签名。原生机位档仅覆盖24字节旋转，保留游戏位置；拉远档写原有位置/旋转48字节。两档共享鼠标跟随方向，FOV及其后字段均保留。两档HUD都使用当前相机回调得到的实际位置。

安装菜单仍只负责选择三种导弹安装范围。自动化覆盖原生档只写旋转、保留位置、拉远几何/偏移、FOV保留、剧情接管恢复、同地址任务重用、仅回中一次、C键返回、视角切换保留目标、可选字段失效、两档运行时切换和F3一次按键一次切换。真实电影镜头和不同任务仍需试飞确认；不能由模拟测试声称已覆盖所有过场。

任务初始化信号参考 UE4SS [RegisterInitGameStatePreHook 官方接口](https://docs.ue4ss.com/lua-api/global-functions/registerinitgamestateprehook.html)。实际任务是否触发这些边界仍以运行日志为准。
