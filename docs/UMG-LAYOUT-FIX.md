# 原生 UMG 布局修复候选

2.3.14-umg-layout-preview.1。保留2.3.13飞控与原生UImage路线，不使用外部叠加窗口。

此前实飞只证明Image挂载成功，未执行位置更新；原实现先把图片隐藏，又要求缓存尺寸有效才能显示，且没有记录提前返回原因。本版拆开初始化与目标投影：先设置明确的64单位圆环、中心锚点与可见状态，约2秒后进入跟随；若几何仍未就绪，保留固定标记并记录原因。

容器优先从实际HudWidget/NonGlowWidget的根Canvas寻找，随后检查AlwaysVisibleCanvas等。仅选择完成布局、可见且比例与画面一致的容器；输出各容器尺寸和返回类型。目标投影使用实际游戏窗口尺寸，再通过标准化锚点放入UMG容器，减少分辨率与DPI混用。

UMG更新安排在本帧飞控上下文更新之后。错误日志区分：gate位掩码、无画面尺寸、未完成布局、无HUD快照、玩家不匹配、快照过期、目标在背后、FOV异常及目标在屏外。错误不会被当成“UMG不支持”。

## 测试

从原Steam入口启动离线任务，先观察中心是否出现固定圆环，再观察它是否开始跟随。前2秒固定标记属于诊断阶段。若圆环跟随后消失，可按F9回中；F7仍控制显示。

若始终没有任何标记，不需要反复测试。正常退出等待归档，日志中的GEOMETRY、ATTACHED及STATE会标明阻塞阶段。实际可见性与性能仍需本次实飞，本地测试不替代游戏验收。

本版继承仅限离线和退出清理要求。停用功能本轮未扩展。
