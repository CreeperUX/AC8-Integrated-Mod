# 2.3.16-phase-preview.1 本地时序测试

以 2.3.15-beta.1 为基础的本地时序预览说明；这些改动已包含在 2.4.0 正式版中。保留世界方向目标、三轴模型、C 自由观察和同帧发布的圆环／方向线快照。

- 原始输入捕获仍运行，累加到配对队列。每个游戏控制帧消费一次，使用该帧的视角换算方向；控制、相机目标和 HUD 暂存从同一次消费取值。独立采集线程不再同时改变目标，避免竞争读取不同代次。最大等待取决于一个游戏回调周期，因此需同时比较跟手性。
- 控制间隔由 QPC 计算，减少16/17ms整毫秒量化；维持原有 1–100ms 范围与生命周期复位，不改变控制模型／增益。
- 圆环和刻度的移动采用 RenderTranslation，尺寸与锚点仅必要时修改；尝试在创建时禁用 PixelSnapping，保留小数像素。接口不接受时明确记录回退到旧布局方式，飞控继续运行。
- 默认混合模式的面板／通知不再读取相机快照、获取目标锁或计算圆环投影。它们仍共享GPU与系统合成资源，不能保证零性能影响。

HUD_PHASE 记录输入消费方式、投影相机数据年龄、重复相机序号；AC8NativeUI MOTION 记录渲染位移与布局调用。统计不等于真实FPS，也不能证明抖动已经消除。没有额外显示平滑或预测。请正常游玩，退出后可用同次日志核对，无需反复按记录键。

本地候选保留先前 Beta 和小白环验证包，以便回退。仅限离线单人。
