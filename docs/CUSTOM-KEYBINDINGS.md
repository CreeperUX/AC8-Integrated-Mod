# 观察与姿态接管自定义键位

由 2.3.17 预览版引入，2.4.0 正式包含。仅限离线单人。

## 图形设置

1. 正常退出游戏并等待启动控制台清理完成。
2. 打开本包 **Start-GUI.cmd**，在“维护与恢复”中点击 **键位设置**。
3. 点击要修改的按键，再按键盘键或鼠标按钮；Esc取消录入。首版支持单键，不支持组合键。F1–F10保留给已有功能。
4. 点击“保存，下次启动生效”。“恢复默认”先修改面板中的值，仍需保存才应用；取消或关闭不保存。
5. 重新从原Steam入口启动。界面不改写游戏键位；姿态接管检测键必须与游戏内实际操纵键一致。

八项分别是自由观察、自由观察放大、抬头／压头、左右滚转、左右偏航。默认C、鼠标右键、S/W、A/D、Q/E，与之前行为一致。自由观察放大必须同时按住观察键与放大键。默认鼠标右键沿用既有原生缩放增强；自定义放大键独立触发约0.18秒长按门槛和连续光学缩放，不需要改绑游戏的目标切换／放大键。自定义路径以2倍光学缩放为基准，使用既有倍率设置扩展缩放变化，具有进入／退出过渡与最低15度FOV限制；其曲线并非游戏原生曲线的精确复刻。

PEACE 中，W/S触发俯仰接管时同时暂停自动滚转，其他轴按自身键位让出；WAR 中按住俯仰／偏航键接管三轴、只按滚转键只接管滚转，见 [WAR 飞控说明](WAR-FLIGHT-CONTROL.md)。改键不会为玩家发送姿态输入，也不会修改油门／刹车或游戏存档。按键与原生游戏绑定、其他Mod或系统快捷键的冲突仍需要玩家核对；本界面阻止本项目八项之间的重复键和既有F1–F10功能键。

## 配置保存与加载

配置在本包根目录Keybindings.ini，保存前保留Keybindings.ini.bak。可用按键令牌见Keybindings.schema.json；None用于手动编辑时取消该项。无效配置在启动前拒绝部署，不会悄悄采用其他键。

启动器将已验证的字符串键名转换为运行副本config.ini的[keybindings]数值表。原生输入、C自由观察状态传递、相机放大和手动接管共同读取一份原子键表。不会在HUD绘制循环反复读取配置。游戏内面板的放大标题显示实际观察键／放大键。

保存时要求游戏已关闭。F10重载只针对本次运行副本；根目录键位配置仍在下次启动部署。已在运行的旧版本不受此设置影响。

## 验证边界

已覆盖默认映射、自定义映射、旧键失效、自由观察目标保持、三轴接管、配置备份／回读／部署、保留键与重复键拒绝、运行游戏时阻止保存，以及真实WPF按钮录入／保存／恢复和主题布局。实机自定义按键效果仍需确认，尤其是游戏内绑定与Mod检测的一致性。
